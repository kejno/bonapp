### Что изменено
- Добавлен экран `/settings` с профилем, брендингом, режимом обслуживания, реквизитами и живым предпросмотром меню.
- API сохраняет настройки заведения, принимает логотип отдельным запросом, а гостевой клиент применяет конфигурацию и real-time смену режима.

### Ключевые решения
- Субдомен доступен только для чтения; загрузка логотипа привязана к tenant из JWT и сохраняет URL только при отправке формы.
- Режим обслуживания хранится в PostgreSQL; создание заказов запрещено в `VIEW_ONLY`.

### Проверка
- `npm test` — unit-тесты API, admin-web и guest-web пройдены; проверка дизайн-токенов и сборка выполнены.
- `npm run typecheck` и ESLint для изменённых файлов прошли. Добавлен Playwright-сценарий предпросмотра и сохранения цвета.
- Playwright не запустился: в окружении отсутствует Chromium (`npx playwright install`).
