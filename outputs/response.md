### Что изменено
- Добавлены CRUD сотрудников, сброс PIN, открытие/закрытие смены и получение активной смены.
- Смена хранит Z-отчёт с суммой, количеством заказов, кассиром и временными метками.

### Ключевые решения
- Использована существующая модель `User`; поддержаны роли `CASHIER`, `WAITER`, `MANAGER`.
- PIN хранится в виде хеша; новый PIN передаётся открытым только в ответе сброса.
- Одна открытая смена на тенант обеспечена частичным уникальным индексом. Счётчик заказов инкрементируется атомарно и сбрасывается при открытии/закрытии смены.
- Вызовы СКНО заменены согласованными с MVP логами-заглушками.

### Как проверить
- `cd apps/api && npm test -- --runInBand` — 55 suites, 512 тестов.
- `cd apps/api && npm run typecheck`
- ESLint для всех изменённых файлов API.
