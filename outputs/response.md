### What changed

Добавлен модуль заказов с созданием, получением деталей, KDS-выдачей и статусной машиной.

### Key decisions

- Позиции заказа хранят снимок кухни, названия и цены; KDS агрегирует их по `kitchenId` и `menuItemId`.
- Гость ищется или создаётся по нормализованному телефону в пределах tenant.
- `PAID` отклоняется статусным API и доступен внутреннему платёжному процессу только после успешного платежа; события публикуются в комнаты гостя и KDS.

### How to verify

```bash
npm test
npm run build
```
