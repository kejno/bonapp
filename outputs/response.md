### Что изменено

Добавлен гостевой поток оплаты картой через bePaid Checkout: создание платежа, перенаправление и проверка результата по статусу сервера. Подпись вебхука проверяется по исходному телу и реквизитам магазина, затем событие ставится в BullMQ.

### Ключевые решения

- Секреты и публичный RSA-ключ остаются в зашифрованных реквизитах; сумма берётся из заказа, чаевые пока равны нулю согласно решению BNP-252.
- Вкладка карты показывается только при подключённом bePaid; возвратный URL не подтверждает оплату.
- Сессия Checkout ограничена 15 минутами; API и PWA URL задаются через `API_PUBLIC_URL` и `GUEST_WEB_URL`.

### Как проверить

- `npm test --workspace=@bonapp/api -- --runInBand` — 76 наборов, 605 тестов.
- `npm test --workspace=@bonapp/guest-web -- --run` — 10 файлов, 32 теста.
- Typecheck API и guest-web, ESLint изменённых файлов — пройдены.
