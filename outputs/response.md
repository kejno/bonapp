### Первопричина
- `StaffTestFixture.adminRequest()` применял `.set()` к фабрике supertest вместо отдельного запроса, из-за чего BNP-412 падал до обращения к API.
- Реализация сброса PIN работала; исходный `Failed Reason` в данных отсутствовал.

### Исправление
- `staff-test.fixture.ts`: использовать agent с Bearer-аутентификацией для авторизованных запросов сотрудников.
- `BNP-412.e2e-spec.ts`: проверять вход с новым PIN и отказ входа со старым.
