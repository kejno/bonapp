# Повторная работа по PR #143

## Issues/Notes

- Блокирующий тред о ручной синхронизации меню остаётся открытым. В репозитории нет адаптеров iiko/r_keeper, контракта импорта или процесса загрузки POS-каталога в меню Bonapp. Тикет не задаёт формат данных провайдеров и правила сопоставления. Возвращать `202 Accepted` без фактического запуска импорта означало бы сообщать об успехе, которого нет.
- Тред по SSRF/передаче API-ключа уже разрешён; текущая реализация health-check использует allowlist, проверяет DNS-адреса и закрепляет публичный IPv4 на время запроса.
- Описание PR в `pr_info.md` относится к исправлению PDF/QR и не соответствует фактической реализации экрана интеграций.
- Необходимы контракт импорта для iiko и r_keeper и согласованные правила сопоставления POS-меню с каталогом Bonapp. До появления этих данных ручная синхронизация не может быть реализована достоверно. Запрос реализации из открытого треда остаётся невыполненным.
- `ci_failures.md`, полный CI-лог, `ticket.md`, корневой `instruction.md` и `AGENTS.md` проекта отсутствуют в подготовленных файлах.
