### Что изменено
- Добавлен защищённый `POST /api/v1/admin/pos/sync-menu`, использующий существующую BullMQ-задачу импорта.
- Импорт обновляет и повторно активирует связанные блюда; после полного успешного импорта отсутствующие позиции мягко скрываются. Некорректный ответ POS не запускает сверку.

### Ключевые решения
- Повторный импорт и ошибки отдельных позиций не скрывают меню: сверка выполняется только для полного импорта без ошибок.
- Позиции без `pos_item_id` остаются вне сверки.

### Проверка
- API unit suite: 70 наборов, 586 тестов — пройдены.
- `npm run typecheck --workspace=@bonapp/api` — пройден.
- ESLint изменённых файлов — пройден.

### Ограничение
- Асинхронная отправка заказа в POS и запись `orders.pos_order_id` в этой итерации не реализованы.
