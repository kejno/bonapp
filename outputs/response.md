### Root Cause
- В `App.tsx` блюда выводились напрямую из загруженного меню; поиска по названию и описанию не было.
- Из-за отсутствия локальной фильтрации гость не мог найти блюдо в каталоге.

### Fix
- `apps/guest-web/src/App.tsx`: добавлено поле поиска и фильтрация загруженных блюд без сетевых запросов; очистка возвращает каталог целиком.
- При отсутствии совпадений отображается сообщение «Ничего не найдено».
- `apps/guest-web/src/App.test.tsx`: добавлен сценарий поиска по названию и описанию, очистки поля и проверки числа запросов.

### Test Coverage
- Новый тест воспроизводил отсутствие поля поиска до исправления.
- `npm run test -w apps/guest-web` — PASSED, 28 тестов.

### Notes
- Поле поиска отображается после успешной загрузки непустого меню.
