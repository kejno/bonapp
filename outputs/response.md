### Root Cause
- Гостевой `App` получал от API `imageUrl`, `isHit` и `isInStopList`, но выводил меню простым списком и не использовал эти поля.
- Также экран показывал номер стола без знака №, а навигации по категориям не было.

### Fix
- `App.tsx`: добавлены навигация категорий, карточки 96×96, двухстрочное описание, отметка хита и greyscale overlay с отключением заказа для стоп-листа.
- `App.test.tsx`: добавлен сценарий с несколькими блюдами, включая хит и позицию в стоп-листе; проверки номера стола согласованы с форматом «Стол №N».

### Test Coverage

- Полный набор `guest-web`: 9 файлов, 28 тестов PASSED.
- `npm run typecheck -w apps/guest-web` — PASSED.
