### Что изменено
Добавлен Socket.IO Gateway с комнатами заказов, кухни и зала, проверкой JWT сотрудников и Redis adapter. Для гостей добавлена ограниченная по времени Table Session с хешированным токеном; Gateway проверяет её привязку к столу и активному заказу.

### Ключевые решения
- События отправляются в комнаты по утверждённой матрице BNP-219.
- Сессии отзываются после оплаты, подключённые клиенты комнаты заказа отключаются.
- Redis adapter подключается при наличии `REDIS_URL`.
