### Что изменено
- Добавлен экран `/order/:orderId/status` с номером заказа, статусами, обратным отсчётом и действием «Добавить ещё».
- Гостевой API возвращает снимок заказа для QR-сессии; WebSocket передаёт изменения только клиентам, авторизованным для стола с этим заказом.
- PATCH статуса заказа персоналом сохраняет изменение и отправляет `order:status_changed`; reconnect повторно загружает снимок и подписывается на комнату заказа.

### Ключевые решения
- QR-токен стола используется для HTTP-запроса и проверки права вступить в комнату заказа.
- Таймер останавливается на `00:00`; отменённый заказ показывает обращение к официанту и скрывает дозаказ.
- Номер заказа форматируется с ведущими нулями, например `#048`.
