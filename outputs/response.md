### What changed
- Добавлены `/staff`, API управления сотрудниками и модель смены с итогами по оплаченным заказам.
- Форма поддерживает четыре роли, временный пароль при создании, редактирование и деактивацию.

### Key decisions
- Вход нового сотрудника использует email и хеш временного пароля; первый вход требует сменить пароль.
- Выручка и число чеков считаются по оплаченным заказам после открытия смены.

### How to verify
- `npm test`
- `npm run typecheck --workspace=apps/admin-web`
- `npm run typecheck --workspace=apps/api`
- `npx eslint <изменённые файлы>`
