# Результат повторной проверки PR #143

## Issues/Notes

- **BLOCKING: ручная синхронизация меню не реализована.** `IntegrationsService.syncMenu` проверяет credentials, затем всегда выбрасывает `ServiceUnavailableException`. В кодовой базе не найдено адаптера iiko/r_keeper, процесса импорта или очереди для запуска задания. Возвращать `202 Accepted` либо имитировать запуск без фактической постановки импорта означало бы скрыть невыполненное требование. Для реализации нужны POS-клиенты/адаптеры и контракт сопоставления импортируемого меню с каталогом Bonapp.
- Проверка health-check сейчас отвергает hostname вне `INTEGRATION_HEALTHCHECK_HOSTS`, запрещает не публичные IPv4 DNS-ответы и подключается к закреплённому IP. Существующий тест подтверждает, что произвольному URL не передаётся API-ключ.
- Описание PR в `input/BNP-165/pr_info.md` по-прежнему описывает PDF/QR и не соответствует текущему diff про экран интеграций; описание следует исправить перед публикацией.
- В `input/BNP-165/pr_discussions_raw.json` четыре inline-треда имеют `resolved: true`. Остальные открытые замечания представлены сводками без `threadId` и `rootCommentId`, поэтому на них нельзя сформировать адресные ответы. `outputs/review_replies.json` содержит пустой список.
- В подготовленном контексте отсутствуют `instruction.md`, `ticket.md`, `pr_files.txt`, `merge_conflicts.md`, `ci_failures.md` и `ci_failures_full.log`. Scope проверен по `input/BNP-165/request.md` и закрытым уточнениям из `existing_questions.json`.
