### Root Cause
- Приложение не извлекало QR-токен из маршрута `/t/:token`, поэтому инициализация стола не запускалась.
- При ошибке разрешения токена отображалось общее сообщение вместо «Стол не найден».

### Fix
- `App.tsx`: читать токен из `/t/:token` и показывать ожидаемый текст ошибки.
- `App.test.tsx`: добавить сценарий неизвестного токена для маршрута `/t/...` и обновить проверку сообщения.

### Test Coverage
- Тест воспроизведения `/t/unknown-token` до исправления — FAILED, после исправления — PASSED.
- Полный набор `guest-web`: 9 файлов, 28 тестов PASSED.

- Поле `failedReason` в подготовленных данных пустое; причина подтверждена воспроизводящим тестом BNP-448.
