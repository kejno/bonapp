### Что изменено

Добавлен маршрут `/kds` с Live KDS-канбаном: четыре колонки, карточки заказов, фильтры цехов, drag-and-drop и Bump.

### Ключевые решения

- Данные загружаются через TanStack Query, изменения статуса отправляются PATCH-запросом с выбранным цехом.
- Socket.io подключается к комнате `tenant_kitchen`; `order:created` добавляет карточку и воспроизводит уведомление Howler.
- Для заказов с несколькими цехами фильтр оставляет одну карточку и показывает только позиции выбранного цеха.

### Как проверить

```bash
npm test
npm run build --workspace=@bonapp/admin-web
```
