## Root Cause Analysis
**Bug**: При открытии `/t/<неизвестный-токен>` гостевое приложение не показывает требуемое сообщение «Стол не найден».
**Root cause**: В `apps/guest-web/src/App.tsx` `qrToken` извлекается только из query-параметра `qr_token`; сегмент пути `/t/:token` не обрабатывается. Из-за этого запрос инициализации не отправляется, и состояние ошибки поиска стола не устанавливается. При ошибке API на поддерживаемом query-маршруте также показывается другое, общее сообщение.
**Impact**: QR-ссылка в формате `/t/<токен>` не запускает инициализацию гостевой сессии; для неизвестного токена ожидаемая ошибка и завершение загрузки не отображаются.
**Fix approach**: Извлекать QR-токен из маршрута `/t/:token` с сохранением поддержки `qr_token` и показывать для неразрешённой сессии точный текст «Стол не найден». Добавить тест неизвестного токена по маршруту `/t/...`.
