## Root Cause Analysis
**Bug**: В QR-меню нельзя отфильтровать блюда по названию или описанию без повторного запроса к API.
**Root cause**: В `apps/guest-web/src/App.tsx` каталог выводится напрямую из `menu`; состояние строки поиска и локальная фильтрация отсутствуют.
**Impact**: Гость не может быстро найти блюдо в уже загруженном каталоге по названию либо описанию. Фильтрация на клиенте не реализована.
**Fix approach**: Добавить локальное состояние поиска и отрисовывать отфильтрованные позиции из загруженного меню; при пустом запросе показывать исходный каталог. Поиск должен охватывать название и описание без новых сетевых вызовов.
