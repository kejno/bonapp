## Root Cause Analysis

**Bug:** по сценарию BNP-473 не удалось подтвердить сбой пакетного создания 10 столов; пустой `Failed Reason` не содержит фактической ошибки.

**Root cause:** `HallsService.bulkCreateTables()` в `apps/api/src/halls/halls.service.ts` формирует последовательные номера, генерирует отдельный `randomUUID()` для каждого стола, записывает пакет через `createMany()` и возвращает созданные записи. Проверки bulk-части в `apps/api/test/BNP-361.e2e-spec.ts` проходят: запись в ответе и БД содержит столы с последовательной нумерацией и разными непустыми токенами. E2E-тест падает позднее, на дополнительном вызове генерации PDF: тестовый модуль не предоставляет `tableQrPdfService.generate`.

**Impact:** заявленный сценарий bulk-создания не воспроизвёлся как продуктовый дефект. Связанный тестовый прогон всё же красный из-за отдельной ошибки обвязки шага генерации PDF, который отсутствует в критериях BNP-473.

**Fix approach:** продуктовый код не менять без воспроизводимого дефекта в bulk-создании. Исправить либо отделить PDF-проверку в тестовой обвязке и повторно выполнить связанный тест; затем уточнить результат автоматизации BNP-361.
