## Root Cause Analysis
**Bug**: Гостевой QR-экран не показывает ожидаемые элементы каталога: карточки с фотографиями, навигацию категорий, отметку хита и оформление блюда из стоп-листа.
**Root cause**: В `apps/guest-web/src/App.tsx` данные категорий и меню выводятся простым списком (`<h4>`/`<ul>`), а тип `MenuItem` не описывает `isHit` и `isInStopList`. Компонент не рендерит ссылки категорий, изображение карточки, hit-бейдж или недоступное состояние; API `MenuService.getGuestMenu` уже возвращает `imageUrl`, `isHit` и `isInStopList`, поэтому потеря происходит в гостевом интерфейсе.
**Impact**: При открытии QR-меню гость видит название, описание и цену блюд, но не может ориентироваться по категориям и визуально отличить хит от позиции в стоп-листе; сценарий BNP-444 не соответствует ожидаемому экрану.
**Fix approach**: Добавить в существующий гостевой экран навигацию по категориям и карточки, которые используют уже возвращаемые API-поля, включая 96×96 изображение, ограничение описания двумя строками, бейдж хита и greyscale overlay для стоп-листа; закрепить сценарий регрессионным UI-тестом на нескольких позициях.
