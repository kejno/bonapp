Экран статуса сохраняет `orderId` в URL при возврате в меню; меню теперь читает его и показывает контекст исходного заказа, если он совпадает с активным заказом этой QR-сессии. В текущем меню нет сценария выбора позиций и API создания заказа/дозаказа, поэтому фактическое добавление позиций к заказу этим PR не реализовано; для полного выполнения замечания нужен отдельный flow оформления дозаказа.
