Состояние `queued` сохраняется до вызова `queue.add()`. После старта воркера API больше не записывает `queued`, поэтому быстрый результат `completed`/`completed_with_errors` не затирается. При ошибке публикации прежнее состояние восстанавливается только если запись всё ещё содержит исходное состояние `queued`.
