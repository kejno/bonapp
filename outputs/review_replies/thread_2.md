При сетевой ошибке/тайм-ауте резервная запись теперь остаётся в `PENDING`, поскольку провайдер мог создать платёж, даже если ответ не получен. Частичный уникальный индекс сохраняет блокировку второго QR для этого заказа. Сверка неопределённого результата требует официального API поиска платежа либо поддерживаемого ключа идемпотентности; в имеющихся материалах этого контракта нет.
