## Результат переработки тестов

**Статус:** ✅ ПРОЙДЕНО
**Тест-кейсы:** BNP-535 — обработка ошибки bePaid; BNP-534 — повторное использование активного запроса ЕРИП

## Что проверено
- Гостевой интерфейс показывает безопасное сообщение при ошибке создания запроса ЕРИП.
- Гость может повторить попытку; тест проверяет успешный ответ после повтора.
- Тестовый секрет не отображается в DOM и не попадает в консольные ошибки.
- Backend-проверки подтверждают корректное состояние платежа, повторный запрос и отсутствие второго запроса провайдеру для активного платежа.

## Результат
- Guest-web: 1 набор, 4 теста — пройдено.
- API: 2 набора, 2 теста — пройдено.

npm run test -w apps/guest-web -- PayPage.test.tsx
