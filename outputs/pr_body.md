## Результат автоматизированного тестирования

**Статус:** ✅ ПРОЙДЕНО
**Тест-кейсы:** BNP-535 — обработка ошибки bePaid; BNP-534 — повторное использование активного запроса ЕРИП

## Что автоматизировано
- Guest-web показывает понятное безопасное сообщение при ошибке ЕРИП, позволяет повторить запрос и не отображает секрет в DOM или консольных логах.
- API проверяет состояние платежа после сбоя, повторную попытку и отсутствие второго запроса провайдеру для активного платежа.

## Результат

- API: 4 набора, 4 теста (BNP-533–BNP-536) — пройдено.
