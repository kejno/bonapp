## Результат автоматизации тестирования

**Статус:** 🚫 ЗАБЛОКИРОВАНО
**Тест-кейс:** BNP-538 — повторная фискализация при сбое СКНО

## Что автоматизировано

- Проверяется выполнение задачи через BullMQ worker с временным Redis и три обращения к мок-СКНО.
- Проверяются фактические интервалы 5 и 30 секунд, статус `FISCAL_FAILED`, пустой номер чека и запись ошибки в NestJS Logger.

## Результат

- Целевой тест пройден: 1 набор, 1 тест.
- Кейс остаётся заблокированным: Sentry alert нельзя проверить без интеграции/тестового пути; критерий «не более трёх попыток» противоречит трём указанным межпопыточным паузам 5/30/120 секунд.

## Запуск

```bash
npm run test -w apps/api -- BNP-538 --runInBand
```
